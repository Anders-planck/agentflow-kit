# Routing reference

| Outcome | Preferred skill flow |
|---|---|
| Configure a new repository | `project-bootstrap` → `setup-matt-pocock-skills` |
| Clarify an uncertain design | `grill-me` or `prototype` |
| Create an implementation spec | `to-spec` (`to-prd` alias on older installs) |
| Break work into tickets | `to-tickets` (`to-issues` alias on older installs) |
| Implement approved work | `implement`; add `tdd` when code behavior needs tests |
| Investigate a failure | `diagnosing-bugs` (`diagnose` alias) |
| Improve boundaries/modules | `improve-codebase-architecture` |
| Review completed code | `code-review` |
| Transfer context | `handoff` |

Serena and ast-grep are tools inside these flows, not mandatory stages.
Context-mode protects large outputs and continuity across every stage.

If two skills match, prefer the one whose output is closest to the user's
requested artifact. An explicit invocation always wins.
